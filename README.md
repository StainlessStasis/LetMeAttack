# LetMeAttack
Separates mouse movement from attacking in Minecraft Dungeons. This mod was made using the [Minecraft Dungeons Mod Kit](https://github.com/Dokucraft/Dungeons-Mod-Kit).

# READ THIS
Left clicking to interact with things will not work, it will ONLY attack!

All this mod does is remaps RootPlayer to left click, and SetDestination to middle mouse. This lets you attack with left click without moving with the mouse, but it also means that you must use middle mouse to interact with things (e.g. selecting a mission from camp). 

# Installation
To install the mod:
1) Locate your game's local files. On Steam, right click on it -> `Manage` -> `Browse local files`. If you own the game through the MC launcher then idk, look it up.
2) Navigate to `Dungeons/Content/Paks`.
3) If you don't already have a mods folder, make one in this Paks directory, and name it EXACTLY `~mods` - tilda included!
4) Download the latest release, unzip it, and drop the `.pak` file into that ~mods folder.
